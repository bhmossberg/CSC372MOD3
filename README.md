# CSC372MOD3 – Introduction to JavaFX

A JavaFX menu app that pulls the system timestamp, saves it to `log.txt` and changes the window's background color. JavaFX examples covering stages, scenes, layout panes, buttons, alerts, menus, CSS styling and canvas drawing are included alongside it.

## Overview

This is **CSU Global CSC372 (Programming II), Module 3: Introduction to JavaFX** (Chapter 17 of *Programming in Java with ZyLabs*). It is an Eclipse e(fx)clipse project: `.classpath` references the JavaFX container and a user library named `JavaFX26`, and `build.fxbuild` is the e(fx)clipse deploy descriptor. All sources are in the `application` package.

## Module 3 Critical Thinking – `Module3.java`

The window is titled "Module 3 Critical Thinking". It is built from a `BorderPane` with a `MenuBar` at the top and a read-only `TextArea` in the center, in a 500×200 `Scene`.

| Menu → Item | Handler (lambda) |
|---|---|
| File → **Pull Date and Time** | Writes `System Time:` plus `LocalDate.now()` and `LocalTime.now()` into the text area |
| File → **Save Date and Time** | Appends the text area contents under a `=== Timestamp Record ===` header to **`log.txt`**, using `PrintWriter(new FileWriter("log.txt", true))`. If no timestamp has been pulled yet, it shows a WARNING alert instead |
| File → **Change Background** | Picks a random green hue (80–140) with `Color.hsb(hue, 0.7, 0.85)`, applies it as the scene fill, and shows an alert with the new hue and the previous one |
| File → **Exit** | Asks for confirmation (`AlertType.CONFIRMATION`) and closes the stage on OK |
| Help → **About Me** | An information alert describing the program |

`log.txt` in the repository is real output from saving timestamps during testing.

## JavaFX examples

| File | Demonstrates |
|---|---|
| `IntroApplication.java` | The basic `Application` lifecycle (`extends Application`, `start(Stage)`, `launch`), with the steps numbered in comments. Draws a `Circle` on a black 400×400 `BorderPane` scene. |
| `SalaryGuiFx.java` | Calculates a salary (wage × 40 × 50) and shows it in a `TextField` on a `Pane`. |
| `SalaryCalcButtonGuiFx.java` | A `GridPane` of `Label`s and `TextField`s with a **Calculate** `Button` whose `EventHandler<ActionEvent>` computes the salary. |
| `SalaryCalcButtonErrorAlertGuiFx.java` | The same calculator, plus an `AlertType.ERROR` dialog ("Enter a positive hourly wage value.") for invalid input. |
| `ButtonSample.java` | Six buttons in a `GridPane`, each with its own lambda handler. |
| `AlertShowcase.java` | One button for each `Alert.AlertType` (NONE, ERROR, CONFIRMATION, INFORMATION, WARNING), plus a sixth that updates a `Text` node. A helper method sets `Hgrow`/`Vgrow` so the buttons fill their grid cells. |
| `MoreButtonStyleExamples.java` | Inline CSS with `setStyle` (`-fx-border-color`, `-fx-background-color`, `-fx-font-size`, `-fx-text-fill`) on buttons in an `HBox`. |
| `MenuExample.java` | A `MenuButton` with three `MenuItem`s. The handlers are written both as an anonymous `EventHandler` class and as a lambda, and print to the console. |
| `HistogramViewerFX.java` / `Main.java` | Draw three colored histogram bars on a `Canvas` through its `GraphicsContext` (`setFill`, `fillRect`). The two files are identical except for the class name. |
| `Clipboard.java` | A scratch file for moving code around, with no runnable class. |
| `application.css` | The empty default stylesheet generated by e(fx)clipse. |

## Build and run

You need a JDK (11 or newer) plus the **JavaFX SDK** (OpenJFX), because JavaFX isn't bundled with the JDK.

**Eclipse:** install e(fx)clipse or add the JavaFX SDK as a user library named `JavaFX26`, then run `application.Module3` as a Java Application.

**Command line:**
```bash
export FX=/path/to/javafx-sdk/lib
mkdir -p bin
javac --module-path $FX --add-modules javafx.controls -d bin src/application/*.java
java  --module-path $FX --add-modules javafx.controls -cp bin application.Module3
```
`Module3` writes `log.txt` to the current working directory.

## Concepts demonstrated
- The JavaFX `Application`/`Stage`/`Scene`/scene-graph model
- Layout panes: `BorderPane`, `GridPane`, `HBox`, `Pane`
- Controls: `Button`, `Label`, `TextField`, `TextArea`, `MenuBar`/`Menu`/`MenuItem`, `MenuButton`
- Event handling with anonymous `EventHandler` classes and lambdas
- `Alert` dialogs of every type, including reading the button a user clicked in a confirmation
- Styling with inline CSS, and HSB colors
- Drawing on a `Canvas` with `GraphicsContext`
- Appending to a text file with `FileWriter(path, true)`
